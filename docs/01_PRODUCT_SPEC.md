# Product / UX Spec

## Source Pair
Một ngân hàng = một pair gồm Facebook + Website. UI có thể chia hai nửa như prototype nhưng phải dùng cùng `source_pair_id`. Delete pair xóa cả hai.

## Benchmark Grid
Group: expand/collapse/edit/delete/drag.
Row: edit/duplicate/delete/drag/move group.
Column: add/edit/delete/drag. MB không xóa.
Edit modal: mỗi bank = Description trái + Score phải.

## Matrix
Ranking: rank, platform, total, score profile, M3.
Radar: MB always-on, max 3 competitor selection, optional leader, tooltip.
Matrix: derived only, không nhập trực tiếp ở trang matrix.
